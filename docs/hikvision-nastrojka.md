# Настройка камер и регистратора Hikvision

Практическая инструкция: IP-камеры + NVR (регистратор) Hikvision.

## Что нужно заранее

- Регистратор (NVR) Hikvision
- IP-камеры Hikvision
- HDD для записи (если ещё не установлен)
- Монитор (HDMI/VGA) и USB-мышь
- Сетевой кабель; для удалёнки — доступ в интернет у NVR
- На ПК (по желанию): [SADP Tool](https://www.hikvision.com/en/support/download/sdk/) — поиск и активация устройств в сети

---

## 1. Подключение оборудования

1. Установи HDD в NVR и закрепи.
2. Подключи камеры:
   - **Вариант A (проще):** в PoE-порты на задней панели NVR
   - **Вариант B:** в PoE-свитч / роутер в той же локальной сети, что и NVR
3. Подключи к NVR: монитор, мышь, питание, LAN (в роутер).
4. Включи сначала NVR, затем камеры (или одновременно, если PoE от NVR).

---

## 2. Первичный запуск NVR

1. Выбери язык и часовой пояс (например, `GMT+3:00` для Москвы).
2. Задай **сложный пароль администратора** и сохрани его.
3. При запросе — активируй устройство.
4. Отформатируй диск: **Configuration → Storage → HDD → Format** (или **Storage → HDD**).
5. Настрой сеть NVR:
   - предпочтительно **статический IP**
   - пример: IP `192.168.1.100`, маска `255.255.255.0`, шлюз `192.168.1.1`, DNS `8.8.8.8`

> Пароль по умолчанию на новых устройствах часто отсутствует — устройство нужно **активировать**. Старые модели иногда используют `admin` / `12345` — сразу смени пароль.

---

## 3. Добавление камер

### 3.1. Камеры в PoE-портах NVR (Plug & Play)

1. Открой **Camera → Camera Management** (или **IP Camera**).
2. Камеры обычно находятся сами.
3. Если канал offline — укажи логин/пароль камеры (часто тот же, что задавал при активации).
4. Проверь live-просмотр по каналам.

### 3.2. Камеры в отдельном свитче / другой сети

1. Убедись, что камеры и NVR в **одной подсети**  
   (например, все адреса вида `192.168.1.x`).
2. На ПК в той же сети запусти **SADP Tool**:
   - найди камеры;
   - активируй неактивированные;
   - задай IP, например: `192.168.1.64`, `192.168.1.65`, …
   - задай пароль администратора.
3. В NVR: **Camera → Add** (ручное добавление):
   - IP-адрес камеры
   - порт управления: обычно `8000`
   - протокол: **Hikvision**
   - пользователь и пароль камеры
4. Сохрани и проверь изображение.

### Типичные порты Hikvision

| Назначение        | Порт (по умолчанию) |
|-------------------|---------------------|
| Служебный / SDK   | 8000                |
| RTSP              | 554                 |
| HTTP              | 80                  |
| HTTPS             | 443                 |

---

## 4. Настройка записи

1. **Configuration → Storage → Schedule** (или **Record → Schedule**).
2. Для нужных каналов выбери:
   - **Continuous** — постоянная запись
   - **Motion** — по движению
   - комбинацию (часто Continuous + Motion)
3. Убедись, что расписание покрывает нужные часы (или 24/7).
4. Проверь индикатор записи на канале.
5. Открой **Playback** и перемотай на несколько минут назад — архив должен открываться.

### Полезные параметры

- **Overwrite** — перезапись старых записей при заполнении диска (обычно включить).
- Качество/битрейт: **Camera → Video** — Main Stream для записи, Sub Stream для удалённого просмотра.

---

## 5. Детекция движения (по желанию)

1. **Camera → Motion Detection** (на канале).
2. Включи детекцию, нарисуй зону.
3. Настрой чувствительность и расписание.
4. В расписании записи отметь тип **Motion**, если нужна запись по событию.
5. При необходимости включи уведомления (e-mail, приложение).

---

## 6. Удалённый доступ с телефона

### Через Hik-Connect (рекомендуется)

1. На NVR: **Configuration → Network → Platform Access / Hik-Connect**.
2. Включи сервис, дождись статуса **Online**.
3. Установи приложение **Hik-Connect** на телефон.
4. Создай/войди в аккаунт.
5. Добавь устройство по QR-коду с экрана NVR или по серийному номеру.
6. Проверь live и playback.

### Через сеть без облака

- Нужен белый IP / проброс портов / VPN.
- Обычно пробрасывают: `8000`, `554`, `80` или `443`.
- **Безопаснее:** VPN в домашнюю сеть, без открытия портов наружу.

---

## 7. Чек-лист после настройки

- [ ] NVR активирован, пароль задан
- [ ] HDD отформатирован, виден в Storage
- [ ] Все камеры online, картинка есть
- [ ] Запись идёт, Playback открывается
- [ ] Время и часовой пояс верные
- [ ] (Опционально) Hik-Connect online, телефон видит объект

## 8. Роутер видит камеры и NVR, а NVR камеры не видит

Типичная схема (Keenetic / общий свитч):

| Устройство | IP | Где в роутере |
|------------|-----|----------------|
| Keenetic   | `192.168.1.1` | шлюз |
| NVR        | `192.168.1.116` | порт 1 |
| Камера 1   | `192.168.1.3` | через PoE-свитч (порт 8) |
| Камера 2   | `192.168.1.4` | через PoE-свитч (порт 8) |

Автопоиск на NVR (`Список сетевых устройств`) часто **пустой**, даже если Keenetic уже раздал IP. Это нормально — добавляй вручную.

### Что сделать на NVR

1. Меню → **Камера → IP-канал**.
2. Нажми **Расширенный поиск** → диапазон `192.168.1.1` … `192.168.1.254` → поиск.
3. Если список всё равно пустой — **+ Добавить свое** (ручное добавление) для каждой камеры:

| Поле | Значение |
|------|----------|
| IP | `192.168.1.3` и отдельно `192.168.1.4` |
| Порт | `8000` |
| Протокол | **Hikvision** (если не зайдёт — **ONVIF**) |
| Пользователь | `admin` |
| Пароль | пароль **камеры** (не обязательно пароль NVR) |

4. Сохрани → проверь статус канала (должно стать Online) и картинку.

### Если вручную не добавляется / браузер не открывает камеру

Неактивная камера Hikvision часто **не открывается в браузере**. Роутер её «видит» (IP/MAC есть), но веб и NVR — нет. Нужен **SADP**.

1. С ПК в той же сети (`192.168.1.x`) проверь ping:
   ```text
   ping 192.168.1.3
   ping 192.168.1.4
   ```
2. Скачай и установи **SADP Tool** (официально Hikvision).
3. Запусти SADP от имени администратора, ПК по кабелю к Keenetic (без VPN).
4. В списке должны появиться камеры `192.168.1.3` / `192.168.1.4` (или Inactive).
5. Если статус **Inactive / Не активировано**:
   - выбери камеру → **Activate**
   - задай пароль администратора
   - при необходимости включи Hik-Connect
6. После активации снова открой в браузере:
   - `http://192.168.1.3`
   - `https://192.168.1.3` (если http не отвечает)
7. Затем на NVR добавь камеры вручную (IP / порт `8000` / пароль камеры).

| Результат ping | Что значит |
|----------------|------------|
| Есть ответы | камера жива → активируй через SADP |
| Нет ответов | питание/кабель/PoE-свитч, или IP уже не тот |

### SADP видит NVR, но камеры не видят ни SADP, ни NVR

Роутер (Keenetic) может показать IP/MAC камер (`192.168.1.3`, `192.168.1.4`), а discovery при этом пустой. Значит: линк/DHCP есть, а сервис камеры (веб/SADP) не отвечает. Часто виноват **PoE‑свитч**, слабое питание или камера «зависла».

У тебя на NVR есть вкладки **Настройки PoE** / **Привязка PoE** — камеры лучше сажать **напрямую в PoE‑порты NVR**.

#### Шаг A — нет ноутбука, камеры в другом помещении

Камеры не снимай. Варианты по простоте:

**1) Сделай на месте у камер (без ПК):**

1. Перезагрузи **PoE‑свитч** (питание выкл 30 сек → вкл), подожди 2–3 минуты.
2. На каждой камере зажми **RESET** 15–20 сек (питание должно быть), отпусти.
3. Подожди ещё 2–3 минуты.
4. Вернись к NVR → **Камера → IP‑канал → Обновить** и **Расширенный поиск** (`192.168.1.1`–`192.168.1.254`).
5. Если появились — **Активировать** / **+ Добав.**  
   Если нет — **+ Добавить свое** на `192.168.1.3` и `192.168.1.4`, порт `8000`.
6. На Keenetic проверь, что `.3` / `.4` снова в списке клиентов.

**2) Используй обычный домашний ПК** (у тебя в сети уже есть, напр. «Computer Eduard»):

1. Поставь SADP на этот ПК, запусти от администратора.
2. ПК лучше по кабелю в Keenetic, VPN выкл.
3. После RESET камер и ребута свитча — Refresh в SADP.
4. Активируй камеры, если видны.

**3) Самый надёжный без ноутбука — временно перенести NVR:**

1. Возьми NVR + монитор + мышь в помещение к камерам.
2. Воткни **LAN NVR в тот же PoE‑свитч**, куда камеры (или камеры в PoE‑порты NVR, если кабель достаёт от свитча/коротким патчкордом от патч‑панели — без снятия с потолка).
3. Добавь/активируй камеры на NVR.
4. Верни NVR на место, LAN снова в Keenetic — камеры останутся в списке, если IP те же или DHCP‑резервы на Keenetic.

#### Шаг B — если после RESET всё ещё тишина

1. Индикаторы линка/PoE на свитче и камере.
2. Бюджет PoE: оставь временно **одну** камеру, вторую отключи от порта свитча.
3. На Keenetic проверь, живы ли клиенты `.3` / `.4`.
4. Если свитч managed — выключи изоляцию портов / VLAN.

Дополнительно:

- камеры и NVR в сегменте **Основная**;
- на NVR лучше выключить DHCP и зафиксировать `192.168.1.116`.

## 9. Частые проблемы

| Симптом | Что проверить |
|---------|----------------|
| Нет изображения | кабель, PoE/питание, пароль камеры, канал добавлен |
| Камера Offline | одна подсеть с NVR, IP не конфликтует, пароль верный, протокол Hikvision |
| Роутер видит, NVR нет | ручное добавление по IP, активация камеры, Advanced Search |
| Браузер не открывает камеру | почти всегда нужна активация через **SADP**; проверь ping |
| Нет записи | HDD отформатирован, есть Schedule, не заполнен диск без overwrite |
| Нет в телефоне | интернет у NVR, Hik-Connect включён и Online, верный аккаунт |
| «Incorrect password» | сброс/повторная активация, пароль камеры ≠ пароль NVR |
| Камера не находится в SADP | ПК в той же L2-сети, отключён VPN/firewall, кабель/линк |

### Сброс пароля

- Через **SADP** / официальный процесс с файлом сброса (нужен серийный номер и экспорт кода).
- Либо аппаратный reset на устройстве (если есть кнопка RESET) — после сброса устройство снова нужно активировать.

## 10. Минимальная схема сети

```
Интернет
   │
Роутер (192.168.1.1)
   │
   ├── NVR (192.168.1.100) ──PoE── Камера 1..N
   │         или
   ├── NVR (192.168.1.100)
   └── PoE-свитч ── Камеры (192.168.1.64+)
```
